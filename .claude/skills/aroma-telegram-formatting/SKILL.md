# Что это и чего не касается

Это правила разметки, не содержания. Не меняет факты, дисклеймеры, источники или тон речи (см. `aroma-tone-of-voice`) — только оборачивает уже готовый и проверенный текст в визуальную структуру. Если применение этих правил меняет смысл фразы — это ошибка применения, не повод переписывать факт.

# Формат разметки

Только `Markdown` (legacy), совместимый с `parse_mode: "Markdown"` в Telegram Bot API — `*bold*` (одна звёздочка), `_italic_` (одно подчёркивание). Без вложенных конструкций (`*bold _and italic_*` не поддерживается легаси-парсером и ломает отправку). Каждая звёздочка и подчёркивание должны быть парными — непарный символ где-то в обычном тексте (например, случайное «_» в паре с чем-то ещё в посте) тоже ломает парсинг всего сообщения.

# Подзаголовки по структуре поста

Из `aroma-tone-of-voice` пост состоит из 7 частей. Зацепка и переход к находке (части 1–2) — без подзаголовка, идут как связный текст. Факт (часть 3) — фиксированный узнаваемый подзаголовок, одинаковый в каждом посте:

- 🔬 *Что нашли:*

Части 4–5 («как использовать» и «что учитывать») — подзаголовок обязательно называет масло (или конкретную ситуацию использования), не остаётся общим лейблом без контекста — читатель должен сразу понимать, о чём именно речь, не долистывая назад к началу поста:

- 🌸 *Как использовать [название масла]:*
- ⚠️ *Что учитывать при использовании [название масла]:*

Эмодзи-маркер фиксированный (🔬/🌸/⚠️) — это и есть узнаваемый стиль канала. Текст после эмодзи каждый раз конкретный под пост, не шаблонная фраза без сути.

Часть 7 (живой вопрос к читательнице) — без подзаголовка и без эмодзи-маркера, идёт последней строкой поста, после источника и дисклеймера.

# Буллеты в разделе «Что учитывать»

Списки противопоказаний/условий — не голым тире, а с эмодзи-маркером по категории. Фиксированный набор:

| Категория | Маркер |
|---|---|
| Беременность/кормление | 🤰 |
| Дети | 👶 |
| Животные (кошки/собаки) | 🐾 |
| Прочее (аллергии, фототоксичность, лекарства и т.д.) | 🔸 |

Один пункт — одна категория. Если пункт касается сразу двух категорий — использовать маркер первой по смыслу, не дублировать эмодзи.

# Источник и дисклеймер

- Дисклеймер — курсивом (`_..._`), как уже делает текущий пайплайн.
- Источник — с жирной меткой: `*Источник:* Название, год (DOI/ссылка)`.

# Пример «до/после»

**До (черновик от content-writer, только текст и факты):**
```
Что стоит учитывать:

- Беременность — лаванда считается безопасной при разведении не более 1%.
- Дети 3 месяца – 2 года — лаванда в списке разрешённых масел, но в низкой концентрации.
- Кошка в доме — лаванда не входит в список масел высокого риска.
```

**После (применено форматирование):**
```
⚠️ *Что учитывать:*

🤰 Беременность — лаванда считается безопасной при разведении не более 1%.
👶 Дети 3 месяца – 2 года — лаванда в списке разрешённых масел, но в низкой концентрации.
🐾 Кошка в доме — лаванда не входит в список масел высокого риска.
```

Текст внутри пунктов не менялся — только подзаголовок и маркеры.

# Проверка перед сохранением

- Каждая `*`/`_` использована парой (само сообщение можно мысленно прогнать: если убрать все `*` и `_`, останется ли осмысленный текст ровно без них, без пропущенных фрагментов).
- Подзаголовки 4–5 называют конкретное масло/ситуацию, не остаются общим лейблом («Как применить» без уточнения чего — ошибка).
- Пост заканчивается живым вопросом к читательнице, а не источником/дисклеймером.
- Эмодзи в буллетах расставлены по категориям из таблицы, не декоративно вперемешку.
- Ни один факт, дисклеймер или источник не был сокращён/изменён при оформлении.
