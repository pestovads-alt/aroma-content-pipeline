# Научные базы данных (первичные источники)

- **PubMed / MEDLINE** — основной источник для поиска РКИ, систематических обзоров и мета-анализов.
- **Cochrane Library** — систематические обзоры, обычно самый строгий уровень методологии.
- **Google Scholar** — инструмент для поиска и обнаружения статей, сам по себе не источник авторитетности — использовать только чтобы найти первоисточник, а не как ссылку в посте.

# Специализированные ароматерапевтические источники

- **Tisserand Institute** (tisserandinstitute.org) — основной источник по безопасности, противопоказаниям и дозировкам. Базируется на книге Tisserand & Young, *Essential Oil Safety* (2nd edition) — golden standard в этой узкой области, используй в первую очередь при вопросах безопасности.
- **NAHA** (National Association for Holistic Aromatherapy, naha.org) — профессиональные гайдлайны, применение.
- **IFRA** (International Fragrance Association) — регуляторные ограничения по концентрации веществ (например, лимиты по бергаптену для бергамота).
- **School of Aromatic Studies** — вторичный источник, можно использовать для контекста, но не как единственное подтверждение факта.

# Ветеринарные источники (для противопоказаний животным)

- **VCA Animal Hospitals** (vcahospitals.com)
- **ASPCA** (aspca.org)
- **Pet Poison Helpline** (petpoisonhelpline.com)

Используются вместе — все три при проверке противопоказаний для кошек/собак в доме.

# Профильные журналы (примеры, не исчерпывающий список)

Не единственно допустимые источники, но там регулярно встречаются релевантные РКИ и обзоры:

- *Cephalalgia*, *Journal of Headache Pain*, *Der Schmerz* — головная боль
- *Holistic Nursing Practice*, *Journal of Alternative and Complementary Medicine* — комплементарная/сестринская практика
- *Phytotherapy Research* (Wiley) — фитотерапия, в т.ч. критические обзоры доказательной базы
- *Korean Journal of Family Medicine* и другие журналы семейной медицины — часто публикуют мета-анализы по ароматерапии

# Что НЕ считать авторитетным источником

- Блоги и статьи производителей эфирных масел, включая сайты MLM-компаний (doTERRA, Young Living и подобные) — маркетинговый материал, даже если он ссылается на «исследования». Если такой источник — единственная опора факта, отмечать явно как заявление бренда, не как научный вывод (см. `aroma-ethics`).
- Посты/инфографика в соцсетях без указания на конкретную статью или исследование.
- Wellness-блоги, пересказывающие «исследования показали» без ссылки, которую можно проверить.

# Как использовать при проверке (aroma-fact-checker)

1. Сначала проверить `aroma-safety-rules` — если масло/утверждение там уже задокументировано, не искать заново с нуля.
2. Приоритет силы источника: систематический обзор/мета-анализ (Cochrane, PubMed) > отдельное RCT > специализированный safety-источник (Tisserand/NAHA) для противопоказаний > ветеринарные источники для животных.
3. Для нового утверждения — минимум 1-2 независимых источника сверх исходного, который проверяется.
4. Источник обязательно указывается в итоговом посте (требование из CLAUDE.md и `aroma-safety-rules`).
