# Роль

Помогаешь человеку без опыта программирования развернуть «Аромапост» у себя. Идёшь по шагам, после каждого проверяешь результат командой и только потом переходишь к следующему. Не выполняешь за пользователя вход в аккаунты и не создаёшь ботов — даёшь точную инструкцию, что нажать.

# Шаги установки

1. **Проверь окружение.**
   - `claude --version` — Claude Code установлен и выполнен вход (`claude` → `/login`). Нужна подписка (Pro или выше): конвейер работает через `claude -p` на ней, отдельный API-ключ не нужен.
   - `python3 --version` — нужен Python 3.10+.
   - Ты находишься в корне репозитория (есть `app.py` и `.claude/agents/`). Если нет — предложи `git clone https://github.com/pestovads-alt/aroma-content-pipeline.git` и `cd` в папку.

2. **Установи зависимости.**
   ```bash
   python3 -m venv .venv
   .venv/bin/pip install -r requirements.txt
   ```

3. **Настрой Telegram** (можно пропустить — тогда работает всё, кроме кнопки «Опубликовать»).
   - Скопируй `.env.example` в `.env`.
   - Пользователь создаёт бота у @BotFather (`/newbot`) и вставляет токен в `TELEGRAM_BOT_TOKEN`.
   - Пользователь добавляет бота администратором в свой канал с правом публикации.
   - `TELEGRAM_CHAT_ID` — `@имя_канала` для публичного канала или числовой id (`-100…`) для закрытого.
   - Никогда не выводи содержимое `.env` в ответ и не коммить его — он в `.gitignore`.

4. **Запусти и проверь.**
   ```bash
   .venv/bin/python app.py
   ```
   Открой http://127.0.0.1:5050. Для проверки без затрат лимита скопируй `examples/*.md` в `posts/` — черновик появится в списке, его превью должно открыться.
   Проверка публикации без отправки: `.venv/bin/python telegram_publish.py posts/<файл>.md --dry-run`.

5. **Первый прогон.** Введи на странице название масла или ссылку на исследование. Прогон 5–15 минут. Лог — в `logs/`, черновик — в `posts/`.

# Адаптация под другую нишу

Код менять не нужно — правила ниши живут в скиллах. Для новой темы (нутрициология, психология, фитнес и т.п.) по очереди перепиши вместе с пользователем:

| Файл | Что в нём заменить |
|---|---|
| `.claude/skills/aroma-authoritative-sources` | авторитетные источники ниши |
| `.claude/skills/aroma-safety-rules` | что нельзя обещать, группы риска, возрастные ограничения |
| `.claude/skills/aroma-evidence-criteria` | шкала уровня доказательности (можно оставить как есть) |
| `.claude/skills/aroma-ethics` | этические границы ниши |
| `.claude/skills/aroma-tone-of-voice` | аудитория и тон автора |
| `.claude/skills/aroma-telegram-formatting` | визуальный стиль постов |
| `CLAUDE.md` | одна строка о канале и аудитории |

Агенты в `.claude/agents/` упоминают эфирные масла — замени предметную область в их тексте, не трогая структуру входа/выхода (JSON-схемы), иначе веб-интерфейс не распознает итог прогона.

# Если что-то не работает

- «Не найдена команда claude» — Claude Code не установлен или не в PATH.
- Прогон завершился ошибкой — открой последний файл в `logs/`, найди событие `"type":"result"` и сообщение об ошибке.
- «Unauthorized» при публикации — неверный токен; «chat not found» — бот не добавлен в канал или неверный `TELEGRAM_CHAT_ID`.
- Порт 5050 занят — поменяй `port=` в конце `app.py`.
