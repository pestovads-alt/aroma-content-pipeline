# Иерархия дизайнов исследований (сильный → слабый)

1. Систематический обзор / мета-анализ
2. Рандомизированное контролируемое исследование (RCT) на людях
3. Когортные / наблюдательные исследования на людях
4. Ин витро / на животных
5. Анекдотическое, традиционное применение, кейс-репорты без контроля

# Уровни доказательности

- **Сильный** — мета-анализ или несколько согласованных между собой RCT на людях.
- **Умеренный** — одно RCT на людях, или несколько согласованных наблюдательных исследований на людях.
- **Слабый** — только ин витро/на животных, или единичное малое исследование на людях без контрольной группы.
- **Анекдотический** — научных данных нет вообще, только традиция применения или пользовательские отзывы.

Присваивать уровень нужно по самому сильному из имеющихся подтверждающих источников, но с поправкой вниз, если есть противоречащие данные более высокого уровня.

# Дополнительные критерии проверки качества исследования

- **Размер выборки** — единичные испытуемые (n < 20) снижают уровень доказательности даже для RCT.
- **Контрольная группа / плацебо** — исследование без контроля не может считаться умеренным или сильным, даже если дизайн формально RCT.
- **Конфликт интересов** — спонсор исследования является производителем эфирных масел или добавок → явно отметить в выводе, не понижает уровень автоматически, но требует упоминания.
- **Давность публикации** — исследование старше 15-20 лет проверять на наличие более новых данных, которые могли его опровергнуть или уточнить.
- **Воспроизводимость** — были ли результаты повторены независимой группой исследователей; единичный результат без повторения — сигнал к понижению уровня.

# Когда возвращать FAIL / INSUFFICIENT_DATA

- Заявленный эффект подтверждён только на уровне «слабый» или «анекдотический», а исходный пост претендует на однозначность.
- Найдены прямые противоречия между источниками сопоставимого уровня доказательности.
- Не удалось найти вообще ни одного независимого источника, подтверждающего или опровергающего вывод.
