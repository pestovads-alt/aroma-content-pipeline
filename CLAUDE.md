# Аромапост — контент-конвейер

Канал об эфирных маслах для мам 25–35 лет. Посты готовит конвейер из 4 агентов (`.claude/agents/`), координирует скилл `aroma-content-pipeline`. Правила ниши — в скиллах `.claude/skills/`: безопасность, этика, источники, критерии доказательности, тон, оформление под Telegram.

## Жёсткие границы
- Никогда ничего не публиковать и не отправлять в Telegram или куда-либо ещё. Публикация — только кнопкой в веб-интерфейсе после решения автора.
- Любое утверждение о свойствах масла — с источником и уровнем доказательности.
- Черновики — только в `posts/`, промежуточные JSON шагов — в `posts/.work/<slug>/`.
- Не выходить за пределы папки проекта.

## Стиль ответов
Коротко, по делу, по-русски.
